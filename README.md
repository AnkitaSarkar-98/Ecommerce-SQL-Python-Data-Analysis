# Ecommerce-SQL-Python-Data-Analysis

##  Overview

This project explores an e-commerce dataset to uncover meaningful business insights using **SQL and Python**.

The analysis covers customer behavior, sales performance, product categories, seller performance, payment patterns, customer retention, and year-over-year sales growth.

The project follows a structured **SQL + Python analytics approach**, starting with data preparation and relational analysis in MySQL and continuing with data manipulation and visualization in Python/Google Colab.

---

##  Project Objectives

The main objectives of this project are to:

- Analyze customer locations and purchasing behavior
- Understand sales and product category performance
- Examine payment and installment patterns
- Analyze seller revenue and performance
- Identify relationships between product price and purchases
- Study customer order history and spending patterns
- Calculate cumulative sales and year-over-year growth
- Measure customer retention within 6 months
- Identify the top-spending customers by year

---

##  Tools & Technologies

- **MySQL Workbench** – Database creation, data import, SQL queries, joins and analysis

- **Google Colab** – Python-based analysis and visualization

This project demonstrates how SQL and Python can be combined to perform end-to-end e-commerce data analysis.
